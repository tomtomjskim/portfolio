# 김정식 | 백엔드 개발 포트폴리오

PHP/MySQL 기반 커머스·물류·MES 업무시스템을 개발·운영해 온 백엔드 개발자입니다.

## 업무 사례

### 커머스·물류 변경 영향 분석

사용자 화면, 관리자 기능, DB 상태, batch/cron과 외부 API가 함께 움직이는 기능의 변경 범위를 다룬 사례입니다.

[문서 보기](cases/commerce-change-impact.md)

### 제조 MES 요구사항 모델링

현장의 화면 요청을 입력·조회·상태·통계·권한·DB 규칙으로 정리한 사례입니다.

[문서 보기](cases/mes-requirement-modeling.md)

### 실무형 AI 자동화

로컬 LLM 번역 초안, PHP·JSON 변환 프로그램과 사람 검수를 나눠 실제 언어팩 작업에 사용한 사례입니다.

[문서 보기](cases/practical-ai-automation.md)

## 개인 실사용 프로젝트

### 아이디어 발굴·검토·기획 자동화

스케줄 기반 리서치와 아이디어 생성, 사람의 채택·거절, 기획·설계 문서 생성과 LLM 출력 복구를 연결한 개인 운영 프로젝트입니다.

운영 도메인과 비공개 저장소는 공개하지 않으며, 화면은 합성 데이터로 재현합니다.

[문서 보기](cases/idea-workflow-automation.md)
